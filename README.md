# Shaikh Sahil — Professional Portfolio

A production-ready static portfolio based on the supplied PRD.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive VS Code-inspired design
- `script.js` — theme toggle, language switcher, mobile navigation, scroll reveal, contact mailto
- `resume.pdf` — add your real resume PDF here

## Before deployment
1. Replace `your-email@example.com` in `index.html` and `script.js` with the real email address.
2. Put your actual resume PDF in this folder as `resume.pdf`.
3. Replace `#` live-demo links with the real deployed project URLs.
4. Review social profile URLs.
5. Deploy the folder to GitHub Pages, Netlify or Vercel.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.
